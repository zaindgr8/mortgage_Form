# Abu Ein Holding - Mortgage Solutions

This is the official mortgage application form for **Abu Ein Holding**, a premier mortgage company based in Dubai.

## Features
- Modern, minimalist Next.js application.
- Securely captures applicant details (Name, Contact).
- Integrated with n8n webhook for automated lead processing.
- Optimized for Dubai and GCC markets.

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Tech Stack
- **Framework**: Next.js 15
- **Styling**: Tailwind CSS
- **Integration**: n8n Webhook
